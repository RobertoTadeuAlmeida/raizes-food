# Raízes Food

Backend desenvolvido para uma rede fictícia de lanchonetes,
com foco no gerenciamento de unidades, produtos, estoque,
pedidos, usuários e pagamentos.

## Objetivo

Desenvolver uma API REST utilizando Java e Spring Boot para
centralizar as principais operações da rede Raízes Food.

## Principais funcionalidades

- Autenticação e controle de acesso
- Gerenciamento de clientes e gerentes
- Gerenciamento de unidades
- Gerenciamento do cardápio
- Controle de estoque por unidade
- Criação e acompanhamento de pedidos
- Processamento simulado de pagamentos
- Controle do fluxo de preparação dos pedidos

- Spring Boot
